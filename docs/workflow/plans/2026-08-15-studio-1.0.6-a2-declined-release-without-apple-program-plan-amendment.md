## Mac / Windows product behavior for 1.0.6

### Windows

**Unchanged.** Existing automatic update check → download → restart-and-install remains supported (Windows signing policy separate from A2).

### macOS (ships with existing A1 UX — no new code in this amendment)

| Stage | Behavior that will ship |
|-------|-------------------------|
| Packaging | Ad-hoc (`mac.identity: "-"`); stable Mac remains `internal-unsigned` |
| Check / download | May still detect and download GitHub releases (electron-updater) |
| Restart and install | Known unreliable / fails under ad-hoc (Squirrel code-signature requirement) |
| On install failure (A1) | Safe fixed copy: update downloaded but could not be installed → **install latest version manually** (no raw error leak) |

**Verdict — Plan amendment for Mac updater UX code: NOT required for 1.0.6.**

A1 already maps install-context failures (including signature-domain) to truthful manual-install guidance. Expanding to a Mac-only proactive “manual download only” Settings flow is a **future optional** product improvement and must not silently enter 1.0.6 closeout.

**Known limitation remains open:** Mac automatic update **install** is unsupported/unreliable while builds stay ad-hoc. Do **not** mark the Mac signing/auto-update limitation as fixed.
