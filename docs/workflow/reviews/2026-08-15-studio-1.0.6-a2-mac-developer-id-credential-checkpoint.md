## 5. Exact `MAC_CSC_LINK` format for THIS repo

Evidence:

- Plan A4 / Review binding: prefer `MAC_CSC_*`; value is **base64-encoded `.p12`** (or electron-builder-supported equivalent).  
- Existing Windows pattern: `WINDOWS_CSC_LINK` secret → env for electron-builder (`WIN_CSC_LINK`) **as the secret string itself** (electron-builder accepts certificate file contents as base64 for `CSC_LINK` / platform variants).  
- Current Mac workflow does **not** yet wire `MAC_CSC_*` (A2 Implement will).

**Owner instruction for `MAC_CSC_LINK`:**

1. Export Developer ID Application + private key as a password-protected `.p12`.  
2. Base64-encode the **entire binary `.p12` file** (no PEM armor, no path, no URL unless you deliberately use a private HTTPS URL — **not** recommended here).  
3. Store that single base64 string as the GitHub secret `MAC_CSC_LINK`.  
4. Store the `.p12` password as `MAC_CSC_KEY_PASSWORD` (plain text secret value).

Example encode (run locally on your Mac; do not paste output into chat):

```bash
base64 -i FreshPrintsDeveloperID.p12 | pbcopy
```

(or `base64 -w0 certificate.p12` on Linux)

A2 Implement will map these into the temporary CI keychain / `CSC_LINK` + `CSC_KEY_PASSWORD` (or Mac-equivalent) for packaging — **not done in this checkpoint**.

## 6. Owner — Apple certificate creation

1. Sign in to [Apple Developer](https://developer.apple.com/account) with an account that has **Certificates, Identifiers & Profiles** access.  
2. Confirm **Apple Developer Program** membership is active.  
3. **Certificates** → **+** → select **Developer ID Application** → Continue.  
4. If prompted for a CSR: on your Mac, **Keychain Access** → Certificate Assistant → **Request a Certificate From a Certificate Authority** → enter email / Common Name → **Saved to disk** → choose that `.certSigningRequest` in the portal.  
5. Download the issued certificate and double-click to install into **login** (or System) keychain.  
6. In Keychain Access, confirm the certificate shows under **My Certificates** with a disclosure triangle and a **private key** paired underneath. If there is no private key, signing will fail — recreate CSR on the same Mac and re-issue.

---

## 7. Owner — `.p12` export

1. Keychain Access → **My Certificates** → select **Developer ID Application: …**.  
2. Expand and ensure the private key is selected with the cert (or export the identity as a whole).  
3. File → **Export Items…** → format **Personal Information Exchange (.p12)**.  
4. Set a strong export password (this becomes `MAC_CSC_KEY_PASSWORD`).  
5. Store the `.p12` only on a secure machine; do not commit it.
