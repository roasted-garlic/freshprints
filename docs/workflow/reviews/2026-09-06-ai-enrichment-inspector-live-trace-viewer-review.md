## Automated Test Trace Visibility decision

Automated AI tests can emit the canonical Inspector trace format through the same sink
interface. Only boundary-significant tests are trace-enabled by default/on demand;
ordinary unit tests remain unchanged. Mock/fixture traces use the immutable source label
`AUTOMATED TEST - MOCK/FIXTURE`, identify the fixture/mock provider, and cannot be
displayed as live Gemini/OpenAI output. Test traces are held in memory and optionally
written as bounded JSON under ignored `.tmp/ai-enrichment-traces/`; they do not require
Firestore and are not committed. The Inspector can import, copy, export, and compare
these traces with live traces.

Trace capture is observational: it does not alter prompts, provider calls, retries,
assertions, or persistence and adds zero AI calls.

## Security and behavior review

The design is DEV-first, owner/admin-only, explicitly bounded, and fail-soft. Trace
write/retrieval failures cannot change enrichment outcomes. No API keys, auth headers,
tokens, Secret Manager values, raw images, or unrestricted provider error bodies are
stored. Production remains out of scope. The current provider schema 400 is observed
and made more diagnosable; it is not changed by this workstream.

## Addendum — live trace-enabled automated tests

The implementation may optionally stream deliberately trace-enabled tests to the
same DEV trace collection with `AI_ENRICHMENT_TRACE_LIVE_DEV=1`, using existing
Application Default Credentials. Ordinary tests use the in-memory sink and do
not need Firestore or networking. The Inspector subscribes to the exact trace
document, so a running trace can be opened before completion and stage updates
are visible without polling. Mock/fixture and live-provider source labels remain
immutable and distinct. No extra AI calls or assertion changes occur. If the
existing local environment cannot supply safe Application Default Credentials,
the live-test feed remains disabled and the JSON artifact/import workflow is the
safe fallback; no credentials may be invented.
