## Gatekeeper / install notes (unsigned)

1. Download the `.dmg` from the **draft** GitHub Release (after dual-platform rebuild).
2. Open the DMG and drag Fresh Prints to Applications (or run from DMG for a quick smoke).
3. If macOS blocks launch (“unidentified developer”):
   - Finder → right-click the app → **Open** → confirm Open, **or**
   - System Settings → Privacy & Security → allow the blocked app, **or**
   - Owner-approved quarantine clear for internal staff only (document the exact command used in smoke notes; do not broadly disable Gatekeeper).
4. Do **not** distribute this build publicly until a future signed/notarized phase.
