## Topic verdicts (C-SHARED Formal Review)

### 1. Schema — **pass**

| Field | Verdict |
|-------|---------|
| `source: "staff_gang_sheet"` | Keep |
| `staffGangSheetCycleNumber` | Keep |
| `assignedStaffUserId` | Stop requiring / stop writing |
| `whatnotShowId` / `maxTotalQuantity` | Remain absent |
| Replacement ownership field | **Not necessary** |

### 2. Shared uniqueness — **pass with binding changes**

Must enforce **at most one** Staff sheet in active production states globally:

- Active set: `productionStatus ∈ { open, full, printing }` and `source == staff_gang_sheet`
- **Manual create:** refuse if any active Staff sheet exists; prefer transaction (or equivalent atomic check+create); never silently create a second open sheet
- **Completion TX:** before creating N+1, assert no *other* active Staff sheet exists; create next as `open` without assignee
- **Idempotent retry:** if current already `completed` and exactly one `open` successor exists, return that successor; if zero or >1 open successors, fail closed with clear error (no silent second create)
- **Double-click / concurrent complete:** rely on Admin TX + idempotent path
- **DEV legacy multi-lane opens:** fail closed until owner cleanup — do not auto-merge

### 3. Completion callable — **pass with binding changes**

Reuse `completeStaffGangSheetAndOpenNext`:

- shared #N → completed → shared #(N+1), no `assignedStaffUserId`
- any active staff caller (not assignee-gated)
- keep TX + idempotency as above
- do not add a replacement callable

### 4. Rules / permissionService — **pass with binding changes**

| Actor | Create initial #1 | Manage / allocate / export / complete |
|-------|-------------------|--------------------------------------|
| Owner / admin | Yes | Yes |
| Helper | No | Yes (shared sheet) |
| Customer / Portal | No | No |

- Drop helper-own-assignee Rules gate for Staff updates; keep cycle/`source` immutability
- Do not broaden Whatnot create/update or customer access
- Keep `permissionService` as the Studio expression of these capabilities

### 5. Request origin — **pass (strict)**

| Origin | Decision |
|--------|----------|
| `studio_internal` | **ALLOW** |
| `studio_customer` | **DENY** |
| `portal_customer` | **DENY** |
| missing / unknown | **DENY** |

### 6. Legacy missing-`requestOrigin` — **deny inference (binding)**

Do **not** treat `isInternal === true` as Staff-eligible when `requestOrigin` is absent.

Rationale: `requestOrigin` is optional on the type; silent inference would broaden Staff eligibility without an audited backfill and conflicts with the product rule “persisted `studio_internal` only.”

Implement: keep empty Select / clear “No eligible internal requests” copy when only origin-less or non-internal docs are loaded. Optional future backfill is out of this amendment.

### 7. Add Request empty list — **pass**

Plan root causes validated against code:

1. Strict origin membership drops non-matching / missing origins  
2. Post-filter drops placeholder `value: ""`  
3. Loaded working/queued/printing pages may contain no eligible internals  

Fix: reuse `useShowQueuePrintRequests` + `buildShowQueuePrintRequestOptions` + origin filter; preserve placeholder; **no** Staff-specific request query system.

### 8. AddToShowModal tabs — **pass**

- **Shows:** existing calendar / capacity / split / override unchanged  
- **Staff Gang Sheet:** current open shared sheet only; no calendar/capacity/split/override/auto-create  
- Studio-only; Portal never mounts  

Prefer Staff destination UI local to Studio `AddToShowModal` (do not teach generic `ShowPicker` Staff tabs unless duplication forces it).

### 9. Portal isolation — **pass (preserve)**

Retain existing exclusions/rejects; no Portal Staff destination; Recently Requested skip for `staff_gang_sheet` remains.

### 10. Timer / countdown — **pass**

- Hide production timer card for Staff (`useShowProductionTimer` UI)  
- Hide any schedule countdown / time-until-show messaging for Staff  
- Mark Complete remains on callable — **not** coupled to timer start/finish  
- Whatnot timer + schedule/countdown unchanged  

### 11. One Add Request — **pass with binding**

- Prefer **detail header** Add Request (with Export / Mark Complete)  
- **Binding:** remove Attached-section duplicate for **Staff Gang Sheets only** — do **not** churn Whatnot Attached-section button in this amendment  

### 12. Indexes — **pass with binding**

| Index | Verdict |

DEV index redeploy after implement (owner-authorized).

### 13. DEV fixture reconciliation — **pass with checkpoint**

## Required Changes (binding for Implement)

1. **Eligibility:** ALLOW only persisted `requestOrigin === "studio_internal"`. DENY `studio_customer`, `portal_customer`, missing, unknown. **No** `isInternal` inference for Staff.
2. **Add Request options:** When filtering for Staff, **keep** the empty placeholder option; show clear empty copy when no eligible internals.
3. **One button:** Remove Attached-section **Add Request** for Staff only; keep detail-header action. Leave Whatnot Attached-section button unchanged.
4. **Shared uniqueness (create):** Atomic refuse if any other Staff sheet is `open`/`full`/`printing`; never silent duplicate opens.
5. **Shared uniqueness (complete callable):** TX completes #N and creates unassigned #N+1 only when no other active Staff sheet exists; idempotent completed→single open successor; fail closed on ambiguous successor sets.
6. **Callable auth:** Any staff may complete the shared sheet (drop assignee-only helper check).
7. **Rules:** Drop required assignee; Staff update = staff + immutable `source`/`staffGangSheetCycleNumber`; create = owner/admin only; no Whatnot/customer broadening. Optional allowlist tolerance for leftover assignee on legacy DEV docs only.
8. **permissionService:** Shared manage for any staff on Staff source; create remains owner/admin; no scattered role checks.
9. **Indexes:** Remove assignee composite; **add** `source + productionStatus` (required by uniqueness queries).
10. **Timer/countdown:** Suppress both for Staff; Whatnot unchanged; completion stays on callable.
11. **AddToShowModal:** Studio destination tabs Shows | Staff Gang Sheet per plan; no auto-create; no capacity UX on Staff tab; Portal untouched; Studio Print Requests label **Add to Show / Gang Sheet** only on Studio page.
12. **DEV:** Tolerate assignee field leftover; if multiple active Staff opens exist, fail closed and request owner cleanup before QA — do not auto-heal in Implement.
