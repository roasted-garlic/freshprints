## Summary

Amends the arm64-only implementation for dual native Mac architectures and hard-gates release mutation so branch/`prerelease` validation cannot create or alter GitHub Releases. Fixes the finalize naming defect (spaced/`Fresh.Prints-*` vs canonical `Fresh-Prints-*`).

---

## Finalize failure root cause (prior branch runs)

1. Local/electron-builder artifact names derived from `${productName}` produced `Fresh Prints-…` (space).
2. `gh release upload` normalized spaces to dots → `Fresh.Prints-…` on the draft.
3. Finalize verified `basename` with spaces / later hyphen expectations against dotted GitHub names → false failure / updater mismatch risk.
4. Branch `prerelease` finalize also **created** draft releases (including tag `v1.0.4`) before production merge — sequencing defect.

**Fix:** space-free `Fresh-Prints-Mac-${arch}-${version}-…` / `Fresh-Prints-Windows-${version}-…` at electron-builder; finalize verifies those exact names; rejects `Fresh.Prints-*` and spaces; non-stable finalize exits after artifact verify with `VALIDATION_ONLY_NO_RELEASE_MUTATION=1`.
