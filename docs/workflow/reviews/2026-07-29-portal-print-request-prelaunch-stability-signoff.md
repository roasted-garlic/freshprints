## Summary

The pre-launch Studio and Portal print-request lifecycle is stable. Owner QA v18 passed the complete
Start → Pause → Resume → Finish flow with no Firestore permission error, no false Retry warning or
button, Portal remaining Printed, navigation preserving the terminal state, and Studio locking and
placing the request as completed.

The final defect was an authorization mismatch rather than a failed lifecycle. Studio already sent
the exact completion patch (`status`, `updatedBy`, `updatedAt`), but the Firestore whole-document
schema allowlist omitted two current server-maintained fields, `queueTab` and
`showQueueBiddingAcknowledgment`. Amendment 16 added narrow validation for those fields while
keeping them client-immutable and allowing only the exact staff `active|editing -> completed`
transition.

  button.
